Mở link Shopee

Dán link Shopee (sản phẩm, shop) — hệ thống tự gắn affiliate isclix (url= link bạn dán). Hoặc dán sẵn link go.isclix.com nếu cần.

Nhập link

Link shopee.* được chuyển thành deep link isclix với url= (đã mã hóa) + utm_source=ecor, sub4=oneatweb. Nhấn Enter để gửi. Lịch sử lưu local.
